# Description (à coller dans le corps de la release GitHub)

**TraceZero** est un logiciel Windows de **nettoyage, confidentialité, espace disque et maintenance** —
**local-first, privacy-first**, gratuit, open source (MIT), **sans publicité et sans dark pattern**.

> _Voyez ce qui reste. Nettoyez ce que vous choisissez._

## 📥 Installation

**Version portable (aucune installation)**
1. Téléchargez **`TraceZero-portable.zip`** ci-dessous.
2. Décompressez-le où vous voulez.
3. Lancez **`TraceZero.App.exe`**.

Les données restent dans le dossier (`Data\`) — rien n'est écrit ailleurs. Windows 10/11 64 bits.

**Ou via winget**
```
winget install TraceZero.TraceZero
```

## 🔐 Vérifier l'intégrité (recommandé)

```powershell
Get-FileHash .\TraceZero-portable.zip -Algorithm SHA256
```
Doit renvoyer exactement :
```
32855D8DB59D3599BDF5CC16853DF91A232EE4A81651E70C0FD941F817F0BCFB
```

## ⚠️ « Windows a protégé votre PC » / « Éditeur inconnu »

C'est **normal** et je préfère l'expliquer plutôt que vous demander de baisser votre garde : TraceZero est
distribué **directement** (hors Microsoft Store) et n'est **pas encore signé** par un certificat de code
payant. Windows affiche cet avertissement pour **tout** logiciel non signé, indépendamment de sa
dangerosité.

Après avoir vérifié l'empreinte SHA-256 ci-dessus, vous pouvez cliquer **« Informations complémentaires »
→ « Exécuter quand même »**. Vous pouvez aussi analyser le fichier sur [VirusTotal](https://www.virustotal.com/).

## ✨ Au programme de la 0.1.0

- **Nettoyage Windows** (temporaires, plantages, caches, Corbeille) — tailles réelles, prévisualisation
  par risque, validé par une couche de sécurité qui refuse par défaut.
- **Confidentialité** : ce que Windows sait encore de votre activité, chaque trace expliquée.
- **Navigateurs** : Chrome/Edge/Brave/Vivaldi/Chromium/Opera/Opera GX/Firefox — caches + historique,
  cookies, sessions **en option** (jamais cochés par défaut). Mots de passe et favoris **jamais touchés**.
- **Espace disque**, **doublons** (SHA-256), **applications & démarrage**, **effacement sécurisé**.
- **Santé système** : disque, RAM, activité en direct (CPU/RAM), top consommateurs, indice Windows.
- **Multilingue** (fr/en/de/es), accessible, jamais admin (élévation via un helper séparé).

# Description (paste into the GitHub release body)

**TraceZero** is a Windows **cleaning, privacy, disk-space and maintenance** tool — **local-first,
privacy-first**, free, open source (MIT), **with no ads and no dark patterns**.

> _See what's left. Clean what you choose._

## 📥 Install

**Portable (no installation)**
1. Download **`TraceZero-portable.zip`** below.
2. Unzip it anywhere.
3. Run **`TraceZero.App.exe`**.

Data stays in the folder (`Data\`) — nothing is written elsewhere. Windows 10/11 64-bit.

**Or via winget**
```
winget install TraceZero.TraceZero
```

## 🔐 Verify integrity (recommended)

```powershell
Get-FileHash .\TraceZero-portable.zip -Algorithm SHA256
```
Must return exactly:
```
32855D8DB59D3599BDF5CC16853DF91A232EE4A81651E70C0FD941F817F0BCFB
```

## ⚠️ "Windows protected your PC" / "Unknown publisher"

This is **expected**, and I'd rather explain it than ask you to lower your guard: TraceZero is distributed
**directly** (outside the Microsoft Store) and is **not yet signed** with a paid code-signing certificate.
Windows shows this warning for **any** unsigned software, regardless of whether it is dangerous.

After checking the SHA-256 hash above, click **"More info" → "Run anyway"**. You can also scan the file on
[VirusTotal](https://www.virustotal.com/).

## ✨ What's in 0.1.0

- **Windows cleanup** (temp files, crash dumps, caches, Recycle Bin) — real sizes, risk-based preview,
  gated by a safety layer that refuses by default.
- **Privacy** — what Windows still knows about your activity, each trace explained.
- **Browsers** — Chrome/Edge/Brave/Vivaldi/Chromium/Opera/Opera GX/Firefox: caches + history, cookies and
  sessions **opt-in** (never checked by default). Passwords and bookmarks are **never touched**.
- **Disk space**, **duplicates** (SHA-256), **apps & startup**, **secure erase**.
- **System health** — disk, RAM, live activity (CPU/RAM), top memory consumers, Windows performance index.
- **Multilingual** (fr/en/de/es), accessible, never runs as admin (elevation via a separate helper).

## 🧭 Good to know (honesty)

- **Auto-update is disabled** in this release: update via winget or by downloading the next release.

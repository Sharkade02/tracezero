# Description (paste into the GitHub release body)

**TraceZero** is a Windows cleaning, privacy, disk-space and maintenance tool — local-first,
privacy-first, free, open source (MIT), with no ads and no dark patterns.

## ✨ New in 0.1.2

- **Installer (`.exe`)** — a proper `TraceZeroSetup-0.1.2.exe`: double-click to install (Start Menu
  shortcut, clean uninstall). Per-user, **no admin required** by default. In addition to the portable zip
  and winget.
- **App icon** — the TraceZero logo is now the icon of the app, its shortcut, the taskbar and the
  installer (no more generic .NET icon).

## 📥 Install

- **Installer:** download **`TraceZeroSetup-0.1.2.exe`** below and run it.
- **Portable (no install):** download **`TraceZero-portable.zip`**, unzip, run `TraceZero.App.exe`.
- **winget:** `winget install TraceZero.TraceZero`

Windows 10/11 64-bit.

## 🔐 Verify integrity (recommended)

```powershell
Get-FileHash .\TraceZero-portable.zip -Algorithm SHA256
```
- `TraceZero-portable.zip` → `DAEBDB8D40DBC8EFA941EB342FECFD1B9CF0D9C64DD2798625FD9EE1E7C02604`
- `TraceZeroSetup-0.1.2.exe` → `C27BCFB24D62AAE98415D1F452BFDACB260CC0132C5A03C203832D92CE87A6ED`

## ⚠️ "Windows protected your PC" / "Unknown publisher"

Expected: the binaries are not signed with a paid certificate (distributed outside the Store). Check the
SHA-256 above, then **"More info" → "Run anyway"**. Full feature list: see the
[CHANGELOG](https://github.com/Sharkade02/tracezero/blob/main/CHANGELOG.md).

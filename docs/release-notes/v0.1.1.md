# Description (paste into the GitHub release body)

Small fix release. **TraceZero** is a Windows cleaning, privacy, disk-space and maintenance tool —
local-first, privacy-first, free, open source (MIT), with no ads and no dark patterns.

## 🔧 What's fixed

- **Startup language now follows Windows.** On first launch, TraceZero picks your Windows display
  language (fr / de / es / en, with English as fallback for other languages) instead of always starting
  in French. You can still switch language anytime in **Settings**, and your choice is remembered.

## 📥 Install

**Portable (no installation)** — download **`TraceZero-portable.zip`** below, unzip, run
**`TraceZero.App.exe`**. Windows 10/11 64-bit. Or: `winget install TraceZero.TraceZero`.

## 🔐 Verify integrity (recommended)

```powershell
Get-FileHash .\TraceZero-portable.zip -Algorithm SHA256
```
Must return exactly:
```
2B6AC5A1C613BE5406FB081BA359E42183C7AD893DD1EBC0ED44F6D6BD5CAA81
```

## ⚠️ "Windows protected your PC" / "Unknown publisher"

Expected: the binary is not signed with a paid certificate (distributed outside the Store). Check the
SHA-256 above, then **"More info" → "Run anyway"**. You can also scan it on
[VirusTotal](https://www.virustotal.com/). Full list of features: see the
[0.1.0 release](https://github.com/Sharkade02/tracezero/releases/tag/v0.1.0) and the
[CHANGELOG](https://github.com/Sharkade02/tracezero/blob/main/CHANGELOG.md).
